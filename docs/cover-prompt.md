# 封面提示词

用途：GitHub 开源项目 Video Vision Summary 的主题封面，解释视频转录与关键帧取证如何成为可追溯笔记。

构图：宽幅 2.4:1，左侧约 36% 用于标题，右侧三组工程物件由清楚的橙色箭头连接。第一组视频播放器与字幕条，第二组三个放大查看的关键画面卡片与放大镜，第三组打开的笔记页，带小截图、时间戳和青绿色完成勾。每组下方短标签。

视觉：Jiale 的 AI 工坊原创系列，暖白纸底 #F7F3ED，炭黑 #282B2D 自然粗细墨线，重点珊瑚橙 #F36B40，青绿 #4F8A78 少量标记结果，少量半调网点，清晰留白，亲切漫画与工程说明图结合。主体是视频、帧卡片和笔记。整洁无衬线中文标题。纸面平涂。

逐字文字：品牌“Jiale的AI工坊”；标题“视频分析”；副标题“从视频，到有据可查的笔记。”；流程标签“读转录”“看关键帧”“写笔记”。除这些短文本外，只用示意线条和时间戳表示细节。

图为主题插画，正文使用实际视频帧和示例笔记预览展示产出。
