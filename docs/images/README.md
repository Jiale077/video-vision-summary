# 图片说明

- `hero-jiale-ai-workshop.png`：AI 生成主题封面，已核对标题与流程文字，提示词见 [cover-prompt.md](../cover-prompt.md)。
- `note-preview.png`：实际 [示例 note.md](../../examples/demo/result/note.md) 经 GitHub Markdown API 转成 HTML 后，使用暖白阅读样式在浏览器截图；展示笔记阅读效果，不是独立应用界面。
- 正文的三张视频截图直接来自 `examples/demo/result/frames/`，由本项目抽帧命令生成。
- 示例幻灯片 PNG 在浏览器中按 960×540 从同目录原创 SVG 渲染，内容与 SVG 一致；演示视频由这些 PNG 合成。
