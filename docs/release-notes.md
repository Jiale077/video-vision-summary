# v0.1.0

首个公开版本：把视频转录与选定画面整理成有时间戳、可追溯的 Markdown 笔记。

- 可安装的 `video-vision-summary` 技能，适用于具备本地文件和图片查看能力的 AI 助手。
- 本地视频与已有字幕、可选 whisper.cpp 转写、通过 yt-dlp 获取在线视频。
- 先读转录规划选段，再按时间采样，实际看图后写笔记。
- MIT 许可证，中文图文 README、完整教程、Jiale的AI工坊封面和原创演示材料。
- 19 项检查、真实媒体流程及独立本地 ASR 实测；Linux / macOS CI。

脚本准备材料，视觉理解与笔记撰写由所用 AI 助手执行。具体验证范围见 docs/validation.md。
