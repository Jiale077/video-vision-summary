# 笔记模板

根据内容增减章节，保留证据来源。

```markdown
# 视频标题

- 来源：URL 或用户提供的视频文件名
- 转录：提供的字幕 / 平台字幕 / whisper.cpp + 模型名称
- 分析范围：全文转录、实际查看的帧数与采样时间
- 说明：画面为定点采样，未覆盖所有动画状态

## 先看结论

用一段话说明视频解决什么问题、核心观点及适用条件。

## 时间轴

| 时间 | 主题 | 关键内容 |
| --- | --- | --- |
| 00:00–00:30 | … | … |

## 重点拆解

### 主题一

**视频中的说法：** 转录观点与时间。

**画面证据（00:01:23）：** 实际可见内容及它补足的信息。

![00:01:23 的实际画面](frames/frame-001-000083000.jpg)

**综合理解：** 区分原视频事实和分析者推断。

## 可以怎么用

贴合用户目的给出应用方式；需要时保留限制条件。

## 待核实与未覆盖

列出听不清的名词、看不清的数字、语音与画面冲突及未查看片段。

## 证据索引

- [转录](transcript.md)
- [选段](segments.json)
- [采样帧索引](frames.json)
```
